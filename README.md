# Project Runner

A 3D endless runner set in space, with procedurally generated terrain chunks and a time-based difficulty curve. Jump, drift and dash through obstacles.

## Features
- **Chunk-based procedural world generation** (`WorldGenerator`, `LevelChunk`)
- **Difficulty tiers** that scale obstacle density over time (`DifficultyManager`)
- **Player movement**: jump, drift and dash (`PlayerLocomotion`, `DriftController`)
- **Data-driven design** with ScriptableObject configs for player, camera, terrain, obstacles and decoration
- **ScriptableObject input reader** built on the new Input System (event-based)
- **Object pooling** for obstacles and decorations

## Tech
Unity 6000.0.30f1 · C# · Input System · AI Navigation · Synty Polygon art · space skyboxes

## Run it
1. Open the `Project Runner/` folder with Unity 6000.0.30f1.
2. Open `Assets/Scenes/SampleScene.unity` and press Play.
